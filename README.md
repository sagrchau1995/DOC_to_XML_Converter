# EASY CUSTOMS XML GENERATOR Frontend

Next.js frontend skeleton for the Nepal Customs ASYCUDA XML generation workflow.

This phase only establishes the project folders and typed placeholder modules. Real UI state, API binding, extraction review, and download workflows will be implemented in later phases.

Folders:

- `app/` Next.js routes
- `components/` reusable UI components
- `layouts/` application shell
- `forms/` review and manual override forms
- `tables/` invoice, HS, and validation tables
- `hooks/` workflow hooks
- `services/` API client
- `stores/` client workflow state
- `utils/` formatting and helpers
- `types/` frontend TypeScript types
